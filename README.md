
# Automatic-Elements-Recognition-for-LIBS
LIBS光谱的全自动元素识别


接下来我将会分三部分讲解该项目：
## 思路：
### 为什么会有这个项目？
激光诱导击穿光谱技术是通过将高能激光照射在样品表面形成等离子体，随后通过接收和分析等离子体冷却时的发射光谱，进而获悉样品内部元素种类与含量的技术。

然而，对等离子体发射光谱进行分析时，无论是自由定标模型（Calibration-free Model）还是制作定标曲线（Calibration Curve）都需要知道光谱内部的元素种类。而以往研究人员是怎么知道的呢？都是通过元素的特征谱线进行手动挑选，这样效率和鲁棒性无疑是低下的，所以在老师的建议下，开发了这个用于快速识别等离子冷却光谱内部元素种类的程序。

## 项目结构：
### 基本流程：
光谱导入（Start）-->  寻峰-->  元素梳制作-->  温度迭代-->  温度扫描勘误-->   多峰拟合--> 元素置信度输出（End）
### 详解
寻峰（Wavelet_peakfinding.py）：
本程序使用的寻峰是小波寻峰（Wavelet Peak Finding），为什么选用小波寻峰呢？其实我也没探究过其他寻峰办法，当时是和老师讨论，老师说嘉美师姐做过这个寻峰算法，然后寻峰效果还不错，所以就直接选用了，事实证明，寻峰效果确实不错。
参考文献：陈鹏飞等.一种基于连续小波变换的LIBS光谱自动寻峰方法[J].光谱学与光谱分析,2014， 34（7）：1969-1972.

要理解小波寻峰，我们首先要理解小波变换，它实际上就是一个卷积操作（小波母函数与函数），小波系数就是卷积得出的值，很明显小波系数表征出小波母函数与函数的相似度，系数越大表示相似度越高。而小波尺度可以理解为小波母函数的一个形变，当小波尺度不断变化，并且不断对函数做小波变换时，这就成为连续小波变换，可以得到一个小波系数矩阵（小波系数、小波尺度两个维度）

小波寻峰选用的是与LIBS光谱中峰形相似的Mexh（墨西哥帽）函数作为小波母函数，那么在做小波连续变换的时，随着小波尺度的变化，有峰值位置的地方小波系数始终是高的！所以可以用小波尺度下的小波系数极大值点来确定峰值位置。实际做法是在小波域直接寻找最大值，就可以得到脊线（小波域小波系数极大值的连线），随后再对脊线做挑选，就可以求得原始光谱中的全部峰值。

需要注意的是这里需要设置的参数有很多，详情见程序Wavelet_peakfinding.py内部

元素梳（Elements Comb）：
这个是本项目的核心创新点之一，以往对于元素的识别，多通过单一特征谱线进行，本项目利用元素的全光谱，并且叠加波长、强度双维度，制作成元素特征谱线梳进行元素识别。

元素梳分为两种：理论元素梳与实验元素梳，理论元素梳的波长维度是利用NIST数据库的元素谱线库获得，而强度维度是通过公式（预设10000K）再做归一化获得。实验强度梳则是通过实验光谱全局峰位，首先利用谱线库对峰值进行匹配，在对强度进行归一化获得。
