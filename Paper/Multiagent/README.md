## 目录使用原则

1. 原始数据不覆盖、不直接改写。
2. 正式实验结果不覆盖，每次实验使用独立 `run_id`。
3. 论文中的数字必须能追溯到数据、代码、实验运行或文献证据。
4. 文献事实、实验事实、合理推断和待验证假设必须区分。
5. Agent 不应在没有证据的情况下补充实验参数、性能数字或物理机制。
6. 多个 Agent 不同时修改同一个核心文件；由总控 Agent 负责合并。
7. 先建立论证骨架，再生成完整段落；先核验事实，再进行语言润色。

## Agent 任务启动方式

每次任务应明确：

- 任务目标；
- 输入文件或证据；
- 可修改的文件范围；
- 不允许做的假设；
- 预期输出；
- 验收标准；
- 风险和待决策事项。

建议使用 `workflow.md` 中的任务交接模板。
