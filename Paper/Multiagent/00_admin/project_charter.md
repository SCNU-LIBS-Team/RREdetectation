## 2. 研究任务边界

### 当前假设

本项目拟研究如何从 LIBS 光谱中自动识别稀土元素，可能涉及：

- 光谱预处理；
- 自动寻峰；
- 理论或实验元素梳构建；
- 谱线匹配和冲突峰处理；
- 温度迭代；
- 多峰拟合；
- 元素相似度或置信度计算。

### 必须确认的任务类型

- [ ] 元素存在性识别
- [ ] 多元素分类
- [ ] 定性分析

- [ ] 多元素同时识别

在任务类型确认前，不应在论文中混用“识别”“检测”“分类”和“定量”等术语。

## 4. 初步研究问题候选

以下问题暂作为候选，不视为已经确认的论文主张：

1. 能否利用多条元素特征谱线，而非单条特征线，提高稀土元素自动识别的稳定性？
2. 理论元素梳和实验元素梳在识别任务中的作用是否不同？
3. 温度估计或温度迭代是否会显著影响元素置信度？
4. 谱线冲突、峰形重叠和噪声对识别结果的影响有多大？
5. 当前方法是否优于合理的单谱线或其他基线方法？
6. 方法的有效性是否局限于当前样品、仪器和模拟条件？

每个最终研究问题都必须绑定对应实验或分析结果。

## 5. 初步贡献候选

只有在完成文献和实验核验后，才可以将以下内容写成正式贡献：

- 对识别错误、谱线重叠和适用边界的分析。

不得在证据不足时使用“首次”“最优”“显著领先”或“普适”等表述。
